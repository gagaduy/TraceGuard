# Support

TraceGuard is pre-release community software and currently has no paid support or uptime commitment.

- Use a GitHub bug report when reproducible behavior differs from the documented contract.
- Use a feature request for a concrete product outcome or workflow improvement.
- Use repository discussions, when enabled, for setup questions and design exploration.
- Use the private route in `SECURITY.md` for vulnerabilities or sensitive tenant-isolation concerns.

Before asking for help, remove credentials and personal or production data, identify the branch and commit, include relevant logs with sensitive fields redacted, and describe the expected and actual result.

# TraceGuard UI

This package contains accessible, composable UI primitives used by TraceGuard applications. Components follow the repository's shadcn/ui conventions and keep business state and policy outside the presentation layer.

Every component must expose keyboard focus, preserve native semantics, avoid color-only meaning, and include tests for its accessible role or behavior.
